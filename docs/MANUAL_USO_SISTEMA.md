# Manual de Uso del Sistema Académico

## 1. Objetivo
Este manual describe el uso general del sistema para su operación diaria en escuelas con uno o más planteles.

## 2. Acceso
- Ingresar mediante el dominio de la escuela.
- Capturar usuario y contraseña.
- Verificar el rol activo (coordinador, profesor, prefecto, tutor o alumno).

## 3. Estructura operativa
- Escuela (tenant): contenedor principal de datos.
- Planteles (campus): divisiones internas de la escuela.
- Ciclos escolares: periodos de operación académica.
- Planeación de ciclo: asignación de grupos y materias por ciclo.
- Horarios: distribución de sesiones por grupo, materia y docente.

## 4. Catálogos base
Los catálogos deben mantenerse actualizados antes de iniciar ciclo:
- Modalidades
- Niveles
- Grupos
- Materias
- Profesores
- Planteles

## 5. Flujo recomendado de inicio de ciclo
1. Crear ciclo escolar.
2. Asociar modalidades al ciclo.
3. Configurar grupos en Planeación de ciclo.
4. Asignar materias por grupo.
5. Asignar profesor a cada materia.
6. Crear horarios.
7. Verificar sesiones y reportes.

## 6. Seguridad operativa
- Evitar compartir contraseñas.
- Usar siempre el dominio correcto de la escuela.
- Cerrar sesión al terminar.
- Reportar accesos no reconocidos.

## 7. Soporte
Si se detecta información faltante o inconsistente:
- Confirmar ciclo seleccionado.
- Confirmar modalidad/grupo seleccionado.
- Reportar incidencia con captura de pantalla y hora del evento.
