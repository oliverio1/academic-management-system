Manual del Módulo de Planeaciones Docentes

Sistema de Gestión Escolar

Versión de uso para profesores

Fecha: 06/05/2026

1. Objetivo

Este módulo permite al profesor planear su trabajo académico por asignación, organizando unidades, actividades, recursos, evaluación y fechas de ejecución.

2. Acceso al módulo

  1. Iniciar sesión con perfil Docente.
  2. Entrar al menú lateral Planeaciones.
  3. Seleccionar la materia/asignación donde se trabajará la planeación.

3. Flujo de trabajo recomendado

  1. Elegir asignación.
  2. Crear planeación nueva.
  3. Capturar datos generales.
  4. Agregar renglones de planeación.
  5. Guardar y revisar.
  6. Generar PDF final.

4. Estructura de la planeación

4.1 Datos generales

  • Unidad/Campo formativo: seleccionar la unidad correspondiente.
  • Objetivo: validar que corresponda a la unidad seleccionada.

4.2 Renglones de planeación

Cada renglón organiza un bloque de trabajo y normalmente incluye:

  • Tema
  • Subtemas
  • Apertura
  • Desarrollo
  • Cierre
  • Recursos
  • Evaluación
  • Inicio
  • Término

5. Criterios de captura

  • Usar un renglón por bloque semanal o por subtema relevante.
  • Redactar actividades con verbos observables y medibles.
  • Definir recursos concretos (pizarrón, libro, TIC, etc.).
  • Definir evaluación con evidencias claras (rúbrica, lista de cotejo, producto, exposición, etc.).
  • Asegurar que fechas estén dentro del parcial/ciclo vigente.

6. Guardado, edición y actualización

  • Guardar periódicamente durante la captura.
  • Editar cuando sea necesario ajustar ritmo real del curso.
  • Si existe bloqueo por cierre de parcial, solicitar ajuste a coordinación.

7. Generación de PDF

  1. Abrir la planeación guardada.
  2. Usar la opción PDF.
  3. Validar que se muestren correctamente unidad, objetivo, renglones y fechas.

8. Buenas prácticas

  • Mantener coherencia entre tema, actividad y evaluación.
  • Evitar duplicados de contenido entre renglones.
  • Documentar ajustes relevantes realizados durante el parcial.

9. Solución rápida de problemas

No aparece la asignación: verificar campus activo y ciclo actual.

No aparecen unidades: revisar que el temario esté configurado para la materia.

No guarda cambios: validar campos obligatorios y formato de fechas.

PDF desactualizado: guardar antes de volver a generar.

10. Cierre

Este módulo estandariza la planeación docente y facilita el seguimiento académico por coordinación.
