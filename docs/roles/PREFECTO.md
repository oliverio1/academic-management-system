# Manual de Usuario: Prefecto

## Funciones principales
- Registrar asistencia diaria por grupo.
- Registrar incidencias escolares.
- Dar seguimiento a reportes de conducta.

## Flujo diario sugerido
1. Seleccionar grupo y fecha.
2. Registrar asistencia general.
3. Capturar incidencias relevantes.
4. Reportar a coordinación situaciones críticas.

## Módulos clave
- `prefect/groups`
- `prefect/groups/{group}/attendance`
- `prefect/reports`

## Buenas prácticas
- Registrar asistencia en tiempo real.
- Describir incidencias con claridad y evidencia.
- Escalar casos graves de forma inmediata.
