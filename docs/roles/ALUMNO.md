# Manual de Usuario: Alumno

## Funciones principales
- Consultar materias activas.
- Revisar calificaciones y asistencias.
- Consultar reportes y seguimientos académicos.

## Flujo sugerido semanal
1. Revisar materias y tareas pendientes.
2. Confirmar asistencias y calificaciones.
3. Verificar observaciones del profesor o coordinación.

## Módulos clave
- `student/subjects`
- `student/grades`
- `student/reports`
- `student/followups`

## Buenas prácticas
- Consultar el portal con frecuencia.
- Reportar diferencias de captura oportunamente.
