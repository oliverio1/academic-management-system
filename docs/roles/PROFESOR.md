# Manual de Usuario: Profesor

## Funciones principales
- Consultar asignaciones.
- Registrar asistencias.
- Capturar evaluaciones y calificaciones.
- Gestionar actividades, prácticas y planeación didáctica.

## Flujo diario sugerido
1. Abrir clases del día.
2. Registrar asistencia por sesión.
3. Capturar actividades y calificaciones.
4. Revisar avance de grupo y alumnos en riesgo.

## Módulos clave
- `teacher/assignments`
- `teacher/classes`
- `teacher/evaluation`
- `teacher/didactic-plans`
- `assignments/{teachingAssignment}`

## Buenas prácticas
- Capturar asistencia el mismo día.
- Evitar duplicidad de actividades.
- Validar parcial activo antes de cerrar captura.
